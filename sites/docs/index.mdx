**Democracy Watch** est un outil de veille législative pour les associations, ONG et équipes de
plaidoyer. Il permet de suivre des textes de loi, leurs articles et leurs amendements, de voir qui
les porte et où ils en sont dans le parcours parlementaire. Projet [Data for Good](https://dataforgood.fr),
code sous licence MIT.

## Principes produit

1. **L'information utile à la décision d'abord**, le détail juridique ensuite.
2. **Toujours dire d'où vient une donnée** : officielle, reformulée, calculée ou probable.
3. **Garder le lien** texte → article → alinéa → amendement → auteurs → commission → étape.
4. **Accessible** (RGAA / WCAG AA) : clavier, focus visible, jamais la couleur seule.
