## Écrire un test

- **Tester ce que voit l'utilisateur** : rôles et libellés accessibles (`getByRole`), pas les
  classes CSS.
- Pour un composant ou un écran, utiliser `renderWithProviders` (`@democracy-watch/ui/test-utils`) :
  il fournit le thème et une navigation simulée dont on lit les URL visitées.
- Pour un écran, utiliser `renderScreen` (`packages/screens/src/test-utils.tsx`) : API en mode
  mock sans latence, textes suivis et session choisis par le test.

La CI (`.github/workflows/ci.yaml`) lance lint, types, tests unitaires, build, e2e et pytest à
chaque pull request.
