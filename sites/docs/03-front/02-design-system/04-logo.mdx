Le pictogramme est un **hémicycle dont les sièges forment un œil qui veille**. Sa géométrie est
définie une seule fois dans
[`packages/brand/src/geometry.ts`](https://github.com/dataforgoodfr/democracy-watch/blob/main/packages/brand/src/geometry.ts) :
le composant React, les favicons, l'image de partage et la planche ci-dessous en dérivent.

## Assets générés

`pnpm brand` régénère tout dans `packages/brand/assets/` et copie les fichiers servis dans
`sites/web/public` et `sites/docs/public` :

| Fichier | Usage |
| --- | --- |
| `logo.svg`, `logo-inverse.svg`, `logo-stacked.svg` | logotypes (texte vectorisé, aucune police requise) |
| `picto.svg`, `picto-inverse.svg` | pictogramme seul |
| `favicon.svg`, `favicon.ico` (16, 32, 48) | onglet du navigateur (variante compacte à 2 rangées) |
| `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | écrans d'accueil mobiles |
| `site.webmanifest` | application installable (vert encre / jaune clair) |
| `og-image.png` (1200 × 630) | aperçu des liens partagés |

## En code

```tsx
import { Logo, Picto } from "@democracy-watch/brand";

<Logo size={34} />                  // picto + « Democracy Watch »
<Picto height={24} compact title="Democracy Watch" />
```
