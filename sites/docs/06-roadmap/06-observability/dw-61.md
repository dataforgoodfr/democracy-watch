## Contexte

L'API écrit aujourd'hui des logs texte sur la sortie standard (`server/democracy_watch/log.py`). On passe à OpenTelemetry Python : traces des requêtes, logs JSON corrélés, métriques HTTP.

## Critères d'acceptation

- [ ] instrumentation FastAPI, requêtes PostgreSQL et appels Meilisearch
- [ ] logs JSON avec identifiant de corrélation et `trace_id`
- [ ] export OTLP vers OpenObserve configuré par variables d'environnement, désactivé par défaut en local
- [ ] aucun e-mail, jeton ni corps de requête dans la télémétrie (test pytest)
- [ ] une requête de l'API retrouvée dans OpenObserve (log + trace)
