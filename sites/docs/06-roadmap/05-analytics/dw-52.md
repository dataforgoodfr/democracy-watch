## Contexte

Les écrans ne doivent pas appeler Rybbit directement. Un package `@democracy-watch/analytics` expose `track()` avec un catalogue d'événements typé, et ne fait rien en mode DEV_FRONT ni dans les tests.

## Critères d'acceptation

- [ ] `packages/analytics` : `track(nom, propriétés)` typé par un catalogue d'événements
- [ ] adaptateur Rybbit + adaptateur no-op (DEV_FRONT, tests, absence de configuration)
- [ ] une panne de l'outil d'audience ne casse jamais l'interface
- [ ] aucune propriété libre saisie par l'utilisateur (test unitaire)
- [ ] page de documentation dans « Front › Architecture »
