## Contexte

Le script Rybbit est chargé par le layout de `sites/web` ; la navigation de l'App Router doit compter une page vue par changement d'URL, sans doublon à l'hydratation.

## Critères d'acceptation

- [ ] script chargé depuis l'instance auto-hébergée (`NEXT_PUBLIC_ANALYTICS_URL`, `NEXT_PUBLIC_ANALYTICS_SITE_ID`)
- [ ] une page vue par navigation, vérifiée dans Rybbit
- [ ] rien n'est chargé si les variables sont absentes
- [ ] test e2e : aucun appel d'audience en DEV_FRONT
