## Ajouter un composant

1. Créer le fichier dans le bon dossier de `packages/ui/src` (`core`, `layout`, `filters`, `legislative`) avec son `*.module.css`, qui n'utilise que des `var(--dw-…)`.
2. L'exporter dans `packages/ui/src/index.ts`.
3. Le tester dans `packages/ui/src/components.test.tsx`.
4. Lui créer une page ici, sur le modèle de [Badge](/02-design-system/composants/badge) : Import, Utilisation de base, variantes « Avec … », chacune avec un aperçu `<Preview>` et le code.
